# newsBlend
This is a custom-made dataset used in our NLP and Data Mining for Fake news detection project

newsBlend is a custom-generated dataset created for the study of fake news detection and content classification. It contains a balanced collection of 9,000 news articles, split evenly between:

4,500 real news entries

4,500 fake news entries

The dataset is categorized into five domains, each representing 20% of the total entries:

Moroccan Politics

Moroccan Culture

Media

Health

Tech and Science

This dataset is suitable for tasks such as binary classification (real vs. fake), topic modeling, content analysis, and NLP-based credibility assessments.
